# Tabs
A segmented control for switching between views of the same data (All / Open / Closed).

**Provide:** `items` (`value`, `label`, optional `count`), `value`/`onChange` (or let it manage itself).

- Sits on a `surface-sunken` track with `radius-md`; the active tab lifts to `surface-raised` with `shadow-sm`.
- Use for 2–6 filters. Counts show in a small pill.
