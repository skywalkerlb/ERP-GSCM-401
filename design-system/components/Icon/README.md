# Icon
Line icons on a 24px grid with a 1.75 stroke and round caps; they inherit the text color.

**Provide:** `name` (one of the listed names), optional `size` (16 inside small controls and fields, 18 default, 22 for empty states) and `label` when the icon stands alone and carries meaning.

- The set is a small built-in starter that matches [Lucide](https://lucide.dev) style. For more icons in production, use `lucide-react` with `strokeWidth={1.75}` — never mix icon families.
- Color icons with text tokens (`ink`, `ink-muted`) or the status text tokens; never with decorative 300 shades.
- Do not use emoji as icons.
