# Checkbox
A checkbox with a label for on/off choices and multi-select in tables and filters.

**Provide:** `label`, `checked`/`onChange` or `defaultChecked`, `disabled`.

- 18px box, `radius-xs`, `border-strong` outline; checked fills with `primary` and an `on-primary` check.
- For settings that take effect immediately prefer a toggle; checkboxes are for choices submitted with a form or for row selection.
